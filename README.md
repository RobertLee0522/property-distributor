# 配配看｜ETF 財產分配器

一個可直接發布到 GitHub Pages 的台灣 ETF 預算與月配息試算網站。

## 功能

- 輸入預算，平均配置 0056、00713、00878、00687B
- 可新增、移除常用 ETF，或自行輸入其他股票與 ETF
- 支援零股與整張試算
- 顯示每檔建議股數、投入金額、剩餘現金與預估月息
- 可自行輸入每檔買進的張數與股數，反推該檔投入金額；其餘標的則平均分配剩下的預算
- 即時參考價下方顯示近十個交易日 K 線走勢與平均價格曲線；滑鼠移到 K 棒（手機為點擊）會出現十字游標與當日價格
- 總投入與每月月領可雙向換算
- 可自行修改價格與預估年殖利率
- GitHub Actions 於台股交易時段每 15 分鐘更新官方行情並重新發布
- 可記錄實際買進的日期、張數、股數與總成本，自動算出目前市值、未實現損益、實現損益（已領股息）與總報酬率；資料預設只存在瀏覽器本機
- 已領股息依台股規則認列：要在除息交易日之前買進的配息才算數（除息當天才買的人領不到）
- 已經除息、但發放日還沒到的配息另外列在「已除息待發放」；除息當天股價就先扣掉配息了，所以這筆會一起算進報酬率，空窗期的報酬率才不會憑空少一截
- 12 個月入帳月曆可切換「依預算配置」與「依實際持股」兩個分頁：前者依預算試算，後者依交易紀錄裡實際登記的股數算出每個月可以領多少
- 交易紀錄可選擇透過 [jsonbin.io](https://jsonbin.io) 免費帳號上傳／下載，用同一組 Master Key 與 Bin ID 就能在多台裝置或跟別人互相同步

## 發布到 GitHub Pages

1. 將整個專案推到 GitHub，預設分支命名為 `main`。
2. 到儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment** 的 Source 選擇 **GitHub Actions**。
4. 到 **Actions** 頁籤執行「更新行情並發布網站」，或等待推送後自動執行。

## 本機開發

```bash
npm install
npm run dev
```

GitHub Pages 版本可用：

```bash
npm run build:github
```

> 本工具僅供試算，不構成投資建議。價格與配息以官方公告為準。
